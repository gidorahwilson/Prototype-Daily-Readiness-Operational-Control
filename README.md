# Prototype-Daily-Readiness-Operational-Control
adalah web app berbasis Ruby Sinatra + MySQL untuk memonitor kesiapan operasional harian operator lapangan sebelum bekerja, serta proses verifikasi oleh supervisor dan manajemen oleh manager.

Aplikasi ini dirancang untuk lingkungan kerja operasional (lapangan, industri, tambang, pabrik, pelabuhan, dll) dimana kondisi fisik, mental, APD, dan bukti visual wajib dicek setiap hari sebelum operator mulai bekerja.

🎯 Tujuan Sistem

Menghilangkan proses manual seperti:

Absen kertas
Checklist manual
Supervisor keliling cek satu-satu
Tidak ada bukti visual
Tidak ada histori laporan

Menjadi sistem terpusat, terdokumentasi, dan dapat diverifikasi.

👥 Role Pengguna
Role	Fungsi
Manager	Kelola data user (Manager, Supervisor, Operator)
Supervisor	Verifikasi laporan kesiapan operator
Operator	Mengisi laporan kesiapan harian

🧩 Fitur Utama
✅ Operator Dashboard
Isi nama
Isi tekanan darah
Checklist APD
Kondisi fisik & mental
Upload foto bukti kondisi
Kirim laporan harian

✅ Supervisor Verification Panel
Melihat semua laporan operator dengan status Hadir
Melihat checklist kesiapan
Melihat foto bukti (preview modal)
Memberi catatan/perintah perbaikan
Menentukan status:
Siap Operasi
Perlu Tindakan

✅ Manager Dashboard
Tambah Manager / Supervisor / Operator
